Repo-official integrations

RunWitness ships an OpenClaw plugin package, Hermes skill pack example, and stdio MCP server for MCP-capable hosts.

Trust wording

These integrations are official from the RunWitness side. Upstream-official status waits for each upstream project to accept, list, or ship them.

Alpha limits

RunWitness is not a hosted SaaS control plane, universal OS sandbox, or complete nested-agent tracer.

For security reports, use GitHub private vulnerability reporting or the project security contact.
