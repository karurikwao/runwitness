RunWitness

RunWitness is a local-first control plane for agent work. Let the agent do the work; let RunWitness record policy decisions, commands, file changes, approvals, timelines, and receipts.

Observe

Capture commands, adapter events, file diffs, test signals, and receipt exports in a local SQLite ledger.

Approve

Classify risky actions through policies and preserve approval decisions in the run timeline.

Prove

Export JSON and Markdown receipts that give humans something concrete to review after agent work.

Repo-official integrations are maintained by RunWitness. Upstream-official status requires acceptance by each upstream ecosystem.
