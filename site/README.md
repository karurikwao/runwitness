# RunWitness Launch Site

This folder is a static Cloudflare Pages-ready launch site.

Suggested Pages settings:

- Project name: `runwitness`
- Production branch: `master`
- Build command: leave blank
- Build output directory: `site`

Routes:

- `/`: live demo landing page
- `/launch/`: launch page

Update the links in `index.html` and `launch/index.html` if the final GitHub owner/repo or Cloudflare Pages URL changes.
