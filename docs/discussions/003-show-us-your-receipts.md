# Show Us Your Receipts

Share safe, sanitized examples of what RunWitness helped you verify.

Good examples:

- a local command receipt
- a policy decision that prevented a risky action
- a test run with useful proof
- a rollback dry-run receipt
- a sandbox plan

Before posting, remove:

- secrets and tokens
- private file paths
- customer or production data
- private receipt contents that reveal sensitive work
